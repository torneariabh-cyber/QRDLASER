# 🎨 QR Code Customizer para Gravação a Laser

Sistema completo para personalização de produtos via QR Code, com integração para gravação a laser.

## 📋 Funcionalidades

- ✅ Cliente escaneia QR Code e personaliza seu item
- ✅ Escolha de nome, fonte e ícone
- ✅ Geração automática de QR Code do ticket
- ✅ Painel do operador com lista de tickets
- ✅ Scanner de QR Code integrado
- ✅ Atualizações em tempo real via WebSocket
- ✅ Geração automática de arquivos para LightBurn
- ✅ Interface responsiva para desktop e mobile

## 🚀 Tecnologias

- **Backend:** Node.js + Express
- **Frontend:** HTML5, CSS3, JavaScript Vanilla
- **Comunicação:** WebSocket (Socket.IO)
- **QR Code:** qrcode + @zxing/library
- **Integração:** LightBurn (geração de SVG)
